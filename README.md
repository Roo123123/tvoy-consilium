# Твой консилиум

Клинический тренажёр для врачей. Основной интерфейс — выбранная композиция «Консилиум», переработанная в белой, синей и голубой палитре со шрифтом Montserrat. Содержит 50 клинических задач по шесть подсказок, разборы с источниками, локальный прогресс и 10 достижений.

Главная страница `dist/index.html` сразу открывает «Твой консилиум». Та же версия доступна в `dist/play.html` и `dist/consilium.html`. Предыдущие 10 концепций сохранены в `dist/concepts.html`, их интерактивные варианты — в `dist/legacy-play.html`. Палитра новой версии: #0A3282, #1464FF, #73AFFF, белый и светлые голубые фоны.

## Загрузка на GitHub

1. Распакуйте архив. Откройте полученную папку `case-club-github`.
2. Создайте пустой репозиторий в своём GitHub. Публичность репозитория выберите самостоятельно.
3. Загрузите **содержимое** папки в корень репозитория. Важно сохранить папку `.github` с workflow. Через веб-интерфейс можно начать с `Add file → Upload files`. Проверьте наличие `.github/workflows/pages.yml` после загрузки. Если файловый диалог не показывает скрытые папки, загрузите workflow отдельным файлом через `Add file → Create new file`, указав путь `.github/workflows/pages.yml`.
4. Основная ветка должна называться `main`. Если имя другое, измените `branches` в workflow.
5. Откройте `Settings → Pages → Build and deployment → Source → GitHub Actions`.
6. На вкладке `Actions` запустите `Deploy clinical cases to GitHub Pages` через `Run workflow`, если сборка не запустилась автоматически. После успеха GitHub покажет URL сайта.

Настройка основана на официальной документации: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages . Доступность Pages для приватных репозиториев зависит от тарифа GitHub. Публикация Pages может сделать сайт общедоступным; выбирайте настройки доступа осознанно.

Альтернатива через Git: выполните `git init -b main`, `git add .`, `git commit -m "Add clinical cases prototype"`, добавьте URL созданного репозитория командой `git remote add origin URL_ВАШЕГО_РЕПОЗИТОРИЯ` и выполните `git push -u origin main`.

## Локальный запуск

Из корня проекта выполните `python3 -m http.server 8000 --directory dist`. Откройте `http://localhost:8000`. Для Windows также подходит `py -m http.server 8000 --directory dist`. В проекте нет зависимостей npm и ключей API. Для проверки нужен Node.js 20 или новее.

Архивная галерея находится в `dist/concepts.html`. Параметр `theme` в `legacy-play.html` принимает `clinical`, `night`, `pulse`, `journal`, `atlas`, `bento`, `resident`, `differential`, `synapse`, `garden`. Например: `legacy-play.html?theme=night`. Основной интерфейс «Твой консилиум» всегда использует выбранный дизайн. Параметр `preview=1` показывает явно обозначенный демонстрационный профиль и не сохраняет игровой прогресс.

## Клинические данные

Исходный набор — `dist/data/cases.json`. Сохраняются ID К001–К050, все шесть подсказок, диагноз, допустимые названия, разбор, альтернативы, клинические уточнения и 85 ссылок. Содержание перенесено из подготовленной таблицы без изменения медицинских фактов. Сценарии вымышленные, проверка источников — 28.10.2026. Независимое врачебное рецензирование ещё не проводилось.

После редактирования JSON запустите `npm run prepare-data`: команда обновит `cases.js`, который загружается браузером. Затем выполните `npm run validate` и `npm test`. Изменение опубликованной Google-таблицы автоматически в этот набор не переносится.

Ключи записи: `id`, `diagnosis`, `specialty`, `difficulty`, `clues`, `aliases`, `explanation`, `differential`, `nuance`, `source1`, `source2`. Сложность — предварительная авторская оценка 3–5, а не статистика пилотирования. Принимаются только основной диагноз и явно указанные синонимы с нормализацией регистра, ё/е, пробелов, дефисов и похожих кириллических/латинских букв. Новые синонимы добавляются редактором в `aliases` через точку с запятой; широкие группы диагнозов автоматически не засчитываются.

## Игровая механика

- Кейс дня един для локальной календарной даты. Банк из 50 кейсов циклически повторяется через 50 дней; для длительного ежедневного сервиса потребуется пополнение.
- В свободной практике доступны все 50 кейсов. До ответа названия диагнозов и специальностей скрыты.
- Первая подсказка доступна сразу. После неверного ответа или нажатия «Открыть подсказку» открывается следующая, максимум шесть.
- XP за первое решение: `max(20, 100 - 12 × (подсказки - 1) - 5 × ошибки)`. За повторное решение того же кейса дополнительные XP не начисляются.
- Уровень растёт каждые 500 XP. Это игровая шкала, а не оценка профессиональной квалификации.
- Серия учитывает календарные дни успешной практики. В течение текущего дня вчерашняя серия ещё считается действующей; пропуск полного дня её прерывает.
- После раскрытия ответа кейс ставится на повторение на завтра. Успешное повторное решение снимает его из очереди. Это простая очередь повторения, не полный алгоритм интервального обучения.
- Достижения: первый диагноз, ответ за две подсказки, серии из 3 и 7 дней, 10 уникальных решений, кейс сложности 5, пять направлений, решение без ошибок за три подсказки, три успешных повторения и все 50 кейсов.

## Границы прототипа

Прогресс и избранные оформления хранятся в localStorage этого браузера. Нет регистрации, сервера, переноса прогресса между устройствами или настоящего общего рейтинга. Ограничения хранилища браузера могут отключить сохранение; интерфейс сообщает об этом.

Ответы находятся в статических файлах и видны при просмотре исходного кода. Для честного общего соревнования потребуется серверная выдача подсказок и проверка ответов, авторизация, хранение результатов и защита от повторной выдачи наград. Дневную серию в таком режиме также следует проверять на сервере. GitHub Pages подходит для этого прототипа, но сам по себе не предоставляет такой сервер.

## Визуальные направления

1. Клинический минимализм — спокойный светлый интерфейс с хвойным акцентом.
2. Ночная смена — графитовый экран с боковой навигацией и индиго.
3. Пульс — тёплая игровая подача с маршрутом и крупными наградами.
4. Клинический журнал — антиква, бумага, редакционная сетка.
5. Атлас — тёмно-синяя среда с картой клинического маршрута.
6. Консилиум — светлая модульная bento-композиция с лиловым.
7. История болезни — вкладки клинического дела и тёплая бумажная палитра.
8. Дифференциал — графичная сетка, чёрный и жёлтый.
9. Синапс — тёмный сливовый фон и мягкие фиолетовые слои.
10. Практика — природный шалфей, антиква и растительные мотивы.

Основной выбранный вариант — «Твой консилиум»: композиция «Консилиум» с белой, синей и голубой палитрой и Montserrat. Остальные направления сохранены в архивной галерее для сравнения.
